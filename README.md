# Week 4: Enhancing Web Page Performance and Accessibility

## Project Overview

This project focuses on improving website performance, accessibility, and responsiveness using HTML5 and CSS3. It demonstrates how to create a clean, lightweight, and user-friendly webpage by following modern frontend development practices.

The main goal is to make the website easy to navigate, readable on different devices, and accessible to users with different abilities.

## Objectives

* Improve webpage structure using semantic HTML.
* Optimize CSS by using reusable classes and reducing redundant styling.
* Create a responsive layout for desktop, tablet, and mobile devices.
* Improve keyboard navigation and accessibility.
* Add clear labels to form fields.
* Provide visible keyboard focus indicators.
* Learn how to test webpage performance and accessibility.

## Technologies Used

* **HTML5:** Structures the webpage content.
* **CSS3:** Styles the webpage and creates responsive layouts.
* **Google Chrome:** Runs and inspects the webpage.
* **Lighthouse:** Evaluates website performance and accessibility.
* **WAVE:** Helps identify potential accessibility issues.

## Features

### 1. Semantic HTML

The webpage uses semantic elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>` to organize content meaningfully.

### 2. Performance Optimization

* Uses lightweight HTML and CSS.
* Avoids unnecessary JavaScript and external libraries.
* Uses reusable CSS classes.
* Avoids unnecessary external fonts and large media resources.
* Keeps the stylesheet separate from the HTML file.

### 3. Accessibility Improvements

* Includes a skip-to-main-content link.
* Provides a label for the main navigation.
* Uses clear labels for form fields.
* Provides visible focus indicators for keyboard users.
* Uses readable text and background colors.
* Respects reduced-motion preferences.

### 4. Responsive Design

CSS Grid and media queries allow the layout to adjust to different screen sizes, including mobile phones, tablets, and desktop computers.

### 5. Contact Form

The webpage includes a demonstration contact form with name, email, and message fields. The form does not send or store submitted information because no backend has been implemented.

## How to Run the Project

Follow these steps to run the webpage:

1. Download or copy the project files into a folder named `Week4_Performance_Accessibility`.
2. Ensure that `index.html` and `style.css` are in the same folder.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in a web browser.

Alternatively, install the Live Server extension in Visual Studio Code, right-click `index.html`, and select **Open with Live Server**.

No additional software packages or JavaScript libraries are required.

## Testing and Evaluation

### Performance Testing

Use Google Chrome Lighthouse to evaluate performance and accessibility.

1. Open the webpage in Google Chrome.
2. Press `F12` to open Developer Tools.
3. Open the Lighthouse panel.
4. Select Performance and Accessibility.
5. Run the analysis.
6. Review the results and address any identified problems.

### Accessibility Testing

Use the WAVE Web Accessibility Evaluation Tool to check for potential accessibility issues.

Manual testing can also be performed by navigating the webpage using the `Tab` and `Enter` keys and checking the visible focus indicators.

### Responsive Testing

Use Chrome Developer Tools to test the webpage at different screen sizes and verify that the content remains readable and usable.

**Note:** Actual test results should be recorded after testing. No specific performance or accessibility score is guaranteed.
